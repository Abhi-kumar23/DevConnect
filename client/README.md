# DevConnect — Client

This folder is the **React + Vite** frontend for DevConnect.

For architecture, features, environment variables, Docker, and CI/CD, see the **[root README](../README.md)**.

## Commands

```bash
npm install
npm run dev      # http://localhost:3000 (proxies /api to the backend)
npm run build
npm run lint
```

Configuration: copy `.env.example` to `.env`.
